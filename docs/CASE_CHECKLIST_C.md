# Проверка оригинальных материалов для роли C

17 октября 2026 прочитаны локальные `Кейс_ForteBank.docx`, `How to Win the Datathon.pdf` и состав `open.zip`. Исходные документы и архив не добавлены в Git. Содержимое банковских видео не просматривалось помощником и не отправлялось внешним сервисам.

В архиве 42 MOV и одна XLSX-таблица. Проверка CRC всех видеозаписей при чтении прошла. SHA-256 подтвердил 40 уникальных видео и две группы дубликатов; конкретные имена, хеши и аннотации не публикуются. Размеры видео — 2 426 840–28 718 927 байт. В архиве нет документов по развёртыванию или готового адреса API. Это проверка целостности и состава, не декодирования и не качества модели.

| Требование оригинального ТЗ | Реализация / действие |
| --- | --- |
| Раздел 10: команда создаёт адрес и ключ | локальный генератор ключей, Caddy-конфигурация; фактический публичный адрес ещё нужен |
| POST `/api/v1/analyze`, multipart `file`, MOV, job_id | реализовано; ответ 202 после записи файла и SQLite |
| GET `/api/v1/jobs/{job_id}` | ровно processing/done/failed; ожидание в очереди отображается processing |
| `X-API-Key`, неверный ключ отклоняется | проверка до чтения тела; отдельный ключ обработчиков |
| Два вердикта, несколько событий | проверяется схема, отрицательный результат только с пустым списком |
| 1–3 JPEG base64 и время каждого | валидация JPEG, количества, конечных чисел и диапазонов |
| Не дольше 5 минут | внутренний бюджет 240 с, внешний контроль GPU; фактический прогон ещё нужен |
| FAQ 12–14: 5+ тестовых видео, жюри удалённо | число одновременных запросов не уточнено; не считать 5+ обещанием одновременной обработки |
| FAQ 23: публичный URL обязателен | localhost недостаточен; внешняя сеть остаётся отдельной проверкой |
| FAQ 25: MOV около 29 МБ | запас лимита до 256 МиБ, очередь ограничена |
| FAQ 27: история/экспорт/регистрация не нужны | один экран, восстановление последнего ID без хранения ключа |
| Раздел 7: локальные модели, переносимость | координатор не использует внешние AI, все UI-ресурсы локальны |
| FAQ 28–29: без аудио и идентификации лиц | часть C не анализирует звук/лица; интерфейс проигрывает видео muted |
| Раздел 8: ограничения, модели, правила, запуск | handoff C и отдельные документы A/B; итоговые метрики только после настоящего прогона |

ТЗ требует указать нормативное основание, а FAQ 31 допускает ссылки без точного пункта и открытые документы других банков. Это не разрешает выдумывать норматив или применимость. В текущем командном контракте сохраняем более подробный формат: документ, пункт при наличии и URL в `description`; окончательную проверку делает B.

FAQ упоминает «Недостаточно данных», но опубликованный JSON содержит только два вердикта. C сохраняет опубликованную схему и не добавляет третий. Техническая ошибка — `failed`.

В PDF — общие советы: закрыть обязательный сценарий, измерить результат, сделать простую демонстрацию, подготовить README и репетицию. Совет PDF о необязательном развёртывании не заменяет прямое требование кейса ForteBank. Для питчинга ТЗ даёт 5 минут + 2 минуты вопросов; сначала нужно пройти API-отбор. Пользу и точность не объявлять без измерений.

До сдачи необходимы: готовые правила B, сквозной настоящий ролик на A, публичный HTTPS и прогон из другой сети, проверка нового ракурса командой, итоговые агрегированные метрики. Готовый адрес, GPU или кредиты организатор не предоставляет согласно прочитанному ТЗ.
