Существующие CUDA/Python и Qwen2B используются по путям из `local-paths.json`; тяжёлые файлы не продублированы. Поэтому исходную папку `salamaleykum` пока сохраняйте. Новые зависимости/веса находятся в этой папке и исключены из Git.

Исходное ТЗ сохранено локально в `source_requirements/`. Все видео, кадры, разметка и модельные описания обрабатываются только на компьютере команды.
