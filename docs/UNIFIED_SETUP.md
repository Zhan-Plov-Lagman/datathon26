# Отдельный проект ИТОГ

Папка создана по просьбе пользователя на рабочем столе. Ветка `integration/forte-unified`, основа C `546baf7f9f4d75832a2282bc106ce0f677cf1e31`.

`run.ps1 -Mode Check` проверяет среду. `run.ps1 -Mode Tests` запускает синтетические тесты. `run.ps1 -Mode Interface` открывает только инфраструктуру; это не готовый анализ. `run.ps1 -Mode Service` требует настоящей фабрики обработки: не подставлять тестовую фабрику или фиктивную запись приёмки.

На этом ноутбуке `local-paths.json` содержит абсолютные пути к существующим Python/CUDA и Qwen2B. Они используются без копирования. Дополнительные библиотеки находятся в `.runtime-packages`; новые модели — в `models/`. Исходную папку `salamaleykum` пока нельзя удалять: среда и Qwen2B остаются там.

Исходные версии и незавершённые правки сохранены в `_source_state/`. Эти резервные копии, локальные конфигурации, модели, видео и результаты не публикуются. Копия Git независима: удаление новой папки не меняет исходные проекты. Публикуется только общий код в GitHub-ветке `integration/forte-unified`. Перенос на другой ноутбук без потери его фронтенда описан в `docs/TEAM_INTEGRATION.md`; локальные пути, среда и секреты в Git не передаются.
