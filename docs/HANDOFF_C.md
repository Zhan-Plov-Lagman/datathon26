## Реализовано

- FastAPI: MOV multipart `file`, `X-API-Key`, POST analyze с 202 после сохранения, GET job со схемой жюри, readiness, лимиты размера/очереди. Ошибки не выводят содержимое видео/секреты.
- SQLite: сохранение после перезапуска, атомарная выдача, lease/heartbeat, ограниченные попытки, дедлайн с начала загрузки, защита от позднего/повторного завершения.
- Private API на отдельном 8001 с `X-Worker-Key`; внутренних маршрутов нет на 8000. GPU-транспорт использует отдельный постоянный процесс, останавливает зависший и сохраняет общий бюджет.
- C-адаптер вызывает A `analyze/refine/evidence`, проверяет охват/версии/JPEG/PTS. Пустые события требуют `negative_policy_version`; сырые B results и наблюдения не становятся вердиктом.
- Русский интерфейс: ключ в памяти, готовность, MOV, статус, события, исходные JPEG, переход по времени, восстановление по ID, мобильная ширина. Внешних ресурсов нет.
- Новый запуск одного ноутбука: `scripts.run_local`, `start.ps1 -WithWorker -Python <python-A>`. Проверка ключей/фабрики/занятых портов, API на loopback, один GPU worker, общая остановка и завершение дерева процессов. Дефолтный `start.ps1` сохраняет запуск только координатора для осмотра UI.
- Новый `scripts.check_e2e`: готовность → загрузка → опрос → точная публичная форма → декодирование JPEG. Вывод только технических агрегатов/фиксированных кодов ошибок. Никаких ответов модели/имён файлов/ключей. Удалённый адрес требует HTTPS.

## Настоящий анализ

У A готовы обзор/уточнение/JPEG и технические GPU-замеры, описанные самим A. Русские черновики предназначены только для человека. Пакетов фактов нужной формы и проверенного production evaluator пока нет. У B выбран юридический целевой класс ухода по `LEGAL_DECISION_B.md`, опубликованы `FACT_DEFINITIONS_B.md`. Реестр `0.3.0-departure-basis-checked` сохраняет все пять классов `hypothesis`, `validated_on_local_cases: false`, `public_verdict_ready: false`.

Client interaction switch остаётся экспериментальным наблюдением и не выдаётся как подтверждённое нарушение/уход. Нормативная ссылка сама по себе не активирует класс. Пустые пакеты/неизвестность не дают `no_violation`; семантическая неопределённость не должна маскироваться техническим failed. Пока нет политики, production readiness остаётся недоступной.

Уточнение передачи A/B: в `WORKER_TRANSPORT.md` устранена прежняя общая формулировка об исключении при любой невозможности выдать вердикт. Исключение относится к техническому сбою; семантическая неизвестность требует отдельной согласованной политики. Это исправление документации, поведение кода не менялось, тесты повторно не запускались. Свежий fetch на этом шаге не обнаружил новых A/B-коммитов.

Полный настоящий MOV через API+A+B не проверен. Замера его общего времени, качества, проверки на другом ракурсе и второго GPU у C нет. Публичный HTTPS и доступ из другой сети не проверены.

## Запуск и продолжение

Пользователь выбрал **весь сервис на A, без Tailscale/VPN**, публичный адрес позже. Основная инструкция — [SINGLE_LAPTOP.md](SINGLE_LAPTOP.md): отдельный worktree сохраняет работу A и использует существующие среду/веса. Модель, данные и ключи не копируются в Git.

На A после готовности реальной фабрики, из checkout `feature/api-ui` с локальным `.env`, используя существующий Python A:

```powershell
python -m scripts.run_local
# В отдельном терминале:
python -m scripts.check_api http://127.0.0.1:8000
python -m scripts.check_e2e http://127.0.0.1:8000 '<локальный MOV>'
```

Переменные: `FORTE_API_KEY`, `FORTE_WORKER_KEY`, `FORTE_MODEL_DIR`, `FORTE_RULES_FACTORY`, при необходимости `FORTE_STORAGE`; лимиты в `.env.example`. Worker URL в общей команде принудительно loopback. Хранилище по умолчанию `%LOCALAPPDATA%/Datathon26/runtime`, вне OneDrive. Для отдельного ручного worker: `python -m app.jobs.worker --worker-id gpu-a --coordinator http://127.0.0.1:8001`.

**A/B:** согласовать и извлекать факты, проверить реальные положительные/сложные отрицательные/неопределённые случаи. **B/C:** согласовать evaluator/factory и окончательную/отрицательную политику. **C:** подключить предоставленный контракт и проверить настоящий полный цикл.
