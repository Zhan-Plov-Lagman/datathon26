Видео длительностью 11,633 с завершилось через публичный API за 7,122 с: `done`,
0 событий, 0 JPEG. Этот запуск не проверяет положительное событие или его доказательства.

Выбран явный режим `app.jobs.unified:create_signs_processor`, политика
`signs-targeted.v1`: признаки возможного нарушения либо отсутствие обнаруженных
признаков в выполненном поиске. Охват — **два класса**: уход кассового работника
при незавершённом приёме наличных и хранение личных вещей в кассовом узле.
Проверка текста источников не равна валидации детектора: реестр остаётся
`hypothesis`, `validated_on_local_cases=false`, точность — `unmeasured`.

Последние проверки: API + signs policy — **124 passed, 23,09 с**;
браузер — **4 passed, 24,83 с**; правила — **30 passed + 6 subtests**.
