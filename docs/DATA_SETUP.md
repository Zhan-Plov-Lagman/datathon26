# Локальные данные на трёх ноутбуках

Каждый участник получает исходные материалы по ссылке организаторов или через разрешённую прямую передачу внутри команды. Ссылка на скачивание и сами файлы не включены в Git. У всех должны совпадать исходные байты файлов; разметку организаторов не редактировать.

В текущем рабочем каталоге данные лежат в папке `forte файлы`. На другом ноутбуке можно выбрать любое имя. Ожидаемая структура:

```text
<DATA_DIR>/
  open_labels.xlsx
  videos/
    <видеофайлы MOV>
```

Копия исходного ТЗ также нужна участникам для сверки. Документы и данные передаются отдельно от публичных файлов репозитория. Общий пайплайн содержит требования, но не заменяет оригинал ТЗ.

**Проверка оборудования.**

На каждом ноутбуке выполнить:

```powershell
nvidia-smi --query-gpu=name,memory.total,memory.free --format=csv,noheader
git --version
ffprobe -version
```

Для скрипта ниже необходимы PowerShell, .NET и `ffprobe` в PATH. Python и Excel для аудита не требуются. Установка и запуск модели — отдельная задача A; CUDA-сборку и зависимости фиксировать после успешного теста, а не угадывать по названию GPU.

**Воспроизведение аудита.**

Из корня клонированного проекта:

```powershell
& .\scripts\Inspect-Dataset.ps1 -DataDir '.\forte файлы'
# Если папка названа open:
# & .\scripts\Inspect-Dataset.ps1 -DataDir '.\open'
```

Скрипт читает исходные файлы, извлекает значения из первой таблицы XLSX, проверяет сопоставление имён, метаданные и SHA-256. Он не запускает AI, не извлекает изображения, не использует сеть и не изменяет исходники. Отчёт создаётся в `artifacts/dataset_audit.generated.json`; существующий отчёт не перезаписывается — для повторного запуска задать другой `-OutputPath` внутри `artifacts`.

```powershell
& .\scripts\Inspect-Dataset.ps1 -DataDir '.\forte файлы' -OutputPath '.\artifacts\audit-second-run.json'
```

В поставленном наборе ожидаются 42 видео и 42 строки, 40 уникальных SHA-256, две пары точных копий. Между участниками сравнить хеши и соответствие файлов через разрешённый канал команды. Одна пара копий имеет разные отмеченные моменты; скрипт сохранит обе исходные аннотации. Просмотреть контекст вдвоём, не выбирать автоматически один таймкод.

Парсер времени рассчитан на формат предоставленной таблицы: одно число секунд или два числа — минуты и секунды. Он сохраняет исходный текст и отмечает неподдерживаемые варианты. После обновления набора не переносить эту трактовку на произвольный формат времени без проверки.

**Результат не является проверкой содержания роликов.**

`ffprobe` проверяет метаданные; он не гарантирует успешного декодирования каждого кадра. Разметка типов событий, проверка актуальных норм и полный тест декодирования выполняются отдельно. Смешение латинской X и кириллической Х в именах сохранять: сопоставление исходной таблицы выполняется по точному имени.

Папки с исходниками, `artifacts`, `data`, `frames`, `results`, `uploads` и веса моделей исключены через `.gitignore`. Перед коммитом смотреть `git diff --cached`. Общие схемы, правила из публичных источников, скрипты, код и агрегированные результаты публикуются без содержимого учебных роликов.
