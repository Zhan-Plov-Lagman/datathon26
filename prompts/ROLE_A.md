# Стартовое задание для ИИ участника A

Ты работаешь в роли A проекта Datathon 26 ForteBank на ноутбуке RTX 4050. Сначала прочитай AGENTS.md, TEAM_WORKFLOW.md, FORTEBANK_PIPELINE.md и docs/CONTRACTS.md. Проверь текущую ветку, состояние Git и уже существующий код. Если есть docs/WORKER.md и docs/HANDOFF_A.md, прочитай их. Продолжай существующую реализацию, не создавай параллельную замену.

Твоя область: локальная модель, декодирование MOV, окна кадров, структурированные наблюдения, реальные таймкоды, уточнение интервалов, исходные JPEG-доказательства и GPU-обработчик. Основной кандидат — Qwen3-VL-2B-Instruct в 4 битах. Сначала измерь работоспособность и память, затем скорость целого ролика. Не придумывай нормативные нарушения: реестр правил делает B, публичный API и очередь делает C.

Работай в feature/ml-worker. Реальные видео и описания сцен обрабатывай только локальными программами, не передавай их облачному ИИ, в том числе в выводе инструментов. Для проверки кода используй синтетические fixtures, для реальных данных выводи только технические метрики.

Сделай минимальную проверенную реализацию, тесты важных границ и инструкцию запуска. Запиши фактические результаты в docs/HANDOFF_A.md без банковского контента. Зафиксируй точные входы и выходы для B и C. Если нужный модуль ещё не готов, оставь явный стык и документируй его; не подменяй анализ успешной заглушкой. После проверки закоммить и запушь свою ветку, сообщи коммит и что требуется для интеграции.
