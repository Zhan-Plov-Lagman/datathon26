# Происхождение компонентов интеграции

Исходники команды сохранены в `_source_state/`, их точные SHA-256 — в локальном manifest. 18 октября пользователь подтвердил, что обе дополнительные папки созданы командой для данного хакатона.

| Текущая часть | Исходная реализация | Перенос |
|---|---|---|
| UI/API/SQLite/worker transport | salamaleykum, C 546baf7 | Сохранены |
| PTS и извлечение JPEG | salamaleykum, A | Сохранены; потоковый iter_batches использует тот же таймлайн/rotation |
| RT-DETR и OWLv2 | Самый точный и готовый, cashguard/detectors.py | Адаптированы к локальным путям, PIL RGB, общему deadline и нормализованным координатам |
| IoU-треки и интервалы | Самый точный и готовый, cashguard/scene.py и timeline.py | Новая общая реализация: one-to-one association, expiration, неизвестная роль |
| YOLO Pose | Самый детальный по CV-триггерам, cv_triggers.py | Перенесён модельный подход; свой общий поток, исключены левый crop/фиксированный cashier_id и ложное покрытие |
| Qwen2B NF4 | salamaleykum | Существующие локальные веса/среда без копирования |

CV-детекции — предложения для дальнейшей проверки, не нормативные события. Отрицательный список boxes не равен отрицательному ответу API.

В текущей исходной папке отдельный LICENSE для кода CashGuard не найден: прежнее утверждение плана о MIT было ошибочным. Пользователь подтвердил собственную разработку команды и разрешил интеграцию. Модели/библиотеки имеют отдельные условия. Веса YOLO/Ultralytics используют AGPL/Enterprise модель лицензирования; Enterprise не приобреталась. До внешней передачи необходимо сохранить применимые notices и выполнить условия выбранного способа распространения. Оригинальная реализация третьего проекта целиком не скопирована в runtime.

Ревизии скачанных моделей записываются в `models/*/download_manifest.json` вместе с хешами. Runtime использует local_files_only и явный существующий путь к YOLO; auto-install и телеметрия Ultralytics отключены. Пакеты и веса не входят в Git.

Не перенесены: парсеры юридического вердикта CG/CV, API и хранение этих проектов, fallback `no_violation` после ошибки, фиксированные роли по месту/длительности трека, номинальный FPS для evidence. State-головы, выбор окончательной VLM и финальный evaluator требуют следующих измерений из плана.
