Существующие CUDA/Python и Qwen2B используются по путям из `local-paths.json`; тяжёлые файлы не продублированы. Поэтому исходную папку `salamaleykum` пока сохраняйте. Новые зависимости/веса находятся в этой папке и исключены из Git.

Исходное ТЗ сохранено локально в `source_requirements/`. Видео, кадры, разметка и модельные описания обрабатываются внутри среды команды. Самостоятельный запуск на арендованном сервере согласован пользователем; передача банковского содержимого облачным AI API запрещена.
