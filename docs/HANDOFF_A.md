**Стык B.** `LocalVideoAnalyzer.analyze` возвращает `observations.v1`, `analysis_kind: observations_only`. Получать `windows`, `operation_context`, наблюдения и ограничения обзора. Времена наблюдений вычислены из индексов кадров. Свободный текст модели — визуальная гипотеза, не доказательство применимости правовой нормы. Нужны проверенные правила, исключения, дедупликация событий и оценка качества на независимых сценах. Описание схемы — `docs/CONTRACTS.md`.

**Стык C.** Создать `QwenObserver` и один `LocalGPUWorker` при старте GPU-процесса. Вызовы: `analyze`, `refine`, `evidence`; все принимают общий локальный monotonic-дедлайн. Занятый обработчик выбрасывает `WorkerBusy`, после любой ошибки освобождает блокировку. Между ноутбуками передавать оставшийся бюджет, а не значение monotonic-часов. Не создавать модель на каждом HTTP-запросе. C формирует публичный контракт только после правил B. Общий бюджет включает очередь, анализ, уточнения и выдачу; кооперативный дедлайн внутри модели не заменяет внешний контроль процесса.

**Уточнение для B.** Передавать список `{candidate_id, start_sec, end_sec}` в `worker.refine`; получать `refinements.v1` со списком `{candidate_id, report}`. Окна уточнения — 4 с / перекрытие 1 с / 6 кадров; одинаковые интервалы переиспользуют один результат. Весь список имеет один бюджет. Ответ не подтверждает применимость нормы: B повторно проверяет наблюдения, выбирает опорные времена и только затем C запрашивает `worker.evidence(video_path, {candidate_id: [time1, time2]}, deadline=...)`. Все доказательства извлекаются за один проход видео. Точные сигнатуры и пример — [WORKER.md](WORKER.md).

**Ошибки формата.** При синтаксически неверном JSON разрешён один повтор с более кратким форматом ответа и тем же дедлайном. Повтор содержит те же кадры, не использует метки и не подставляет пустые наблюдения. Ошибка схемы, в том числе неверный индекс кадра, остаётся ошибкой без автоматического исправления. **Что ещё требуется.** B подключает выбор кандидатов и нормативный вердикт, C — транспорт задач, API и очередь. Их реализация не дублируется в этой ветке. Пустые наблюдения не означают `no_violation`. Редкая обзорная выборка может пропустить быстрые действия. Нужны человеческая оценка качества, согласование B/C и сквозной прогон публичного сервиса.
