## Оставшиеся ограничения

- Внутри Runpod сайт отвечает HTTP 200. Авторизованный `/api/v1/readiness`
  отвечает 503, `ready=false`: готовый реальный worker ещё не подключён.
- Внешний proxy на порт 8000 на последней проверке отвечает 404 и для сайта,
  и для readiness. Проверка из интернета не пройдена. После сохранения HTTP-портов
  в Runpod и перезапуска нужно заново запустить API и повторить внешнюю проверку.
- На сервере `.env` сохраняет прежние ключи. База очереди скопирована с проверкой
  SQLite в `/workspace/forte/.runtime`, FORTE_STORAGE обновлён на этот путь.
  Уже запущенный процесс прочитает новый путь только после перезапуска.
- Эти проверки подтверждают интерфейс и транспорт. Они не являются оценкой
  точности на банковских видео или приёмкой всего сервиса.
